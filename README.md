# Java-Day-01-Hello-World
# Java Day 1 - Hello World

This is my first Java program.

The program prints `Hello, World!` on the screen.

## Output

```text
Hello, World!
```

## Concepts Used

* Java class
* `main()` method
* `System.out.println()`
* Basic Java syntax
* Curly braces `{ }`
* Semicolon `;`

## How It Works

1. `public class Main` creates a Java class named `Main`.
2. The `main()` method is the starting point of the Java program.
3. `System.out.println()` prints text on the screen.
4. The program displays `Hello, World!`.

## Java Code

```java
public class Main
{
    public static void main(String[] args)
    {
        System.out.println("Hello, World!");
    }
}
```

## Output

```text
Hello, World!
```

## Goal

The goal of this project is to understand the basic structure and syntax of a Java program.
